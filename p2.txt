Q. Create an ASP.NET Core application using Visual Studio 2026 and implement a
CalculatorService class to perform basic arithmetic operations. Create a separate
xUnit Testing Project in the same solution and write unit test cases to verify the
functionality of addition, subtraction, multiplication, and division operations. Execute
the test cases using Test Explorer and verify the results.

14. Project Structure
The final solution should look approximately like:
CalculatorTesting
│
├── CalculatorAPI
│ │
│ ├── Properties
│ ├── Controllers
│ ├── CalculatorService.cs
│ ├── Program.cs
│ └── appsettings.json
│
└── CalculatorAPI.Tests
│
└── UnitTest1.cs

4. Procedure
Step 1: Open Visual Studio 2026
1. Start Visual Studio 2026.
2. Select Create a new project.

Step 2: Create ASP.NET Core Project
1. Search for:
ASP.NET Core Web API
2. Select ASP.NET Core Web API.
3. Click Next.
Enter the following:

Property Value

Project Name CalculatorAPI
Location Your preferred location
Solution Name CalculatorTesting
4. Click Next.
5. Select an available .NET version.
6. Click Create.
The solution will contain the following project:
CalculatorTesting
│
└── CalculatorAPI

5. Create Calculator Service
We will now create a class containing the methods that need to be tested.
Step 3: Add a New Class
1. In Solution Explorer, right-click the CalculatorAPI project.
2. Select:

Add → Class
3. Enter the filename:
CalculatorService.cs
4. Click Add.

Step 4: Write CalculatorService Code
Replace the contents of CalculatorService.cs with:
namespace CalculatorAPI
{
public class CalculatorService
{
public int Add(int a, int b)
{
return a + b;
}
public int Subtract(int a, int b)
{
return a - b;
}
public int Multiply(int a, int b)
{
return a * b;
}
public double Divide(int a, int b)
{
if (b == 0)
{
throw new DivideByZeroException();
}
return (double)a / b;
}
}
}

6. Create the Testing Project
Step 5: Add xUnit Test Project
1. Right-click the Solution CalculatorTesting.
2. Select:
Add → New Project
3. In the search box, type:
xUnit
4. Select:
xUnit Test Project
5. Click Next.
Enter:
Project Name: CalculatorAPI.Tests
6. Click Next.
7. Select the same .NET version used for the main project.
8. Click Create.
The solution should now look like:
CalculatorTesting
│
├── CalculatorAPI

│ ├── Program.cs

│

7. Add Project Reference
Step 6: Add Reference to Main Project
1. Right-click:
CalculatorAPI.Tests
2. Select:
Add → Project Reference
3. Tick:
CalculatorAPI
4. Click OK.
Now the testing project can use classes from the CalculatorAPI project.

8. Create Unit Test Cases
Step 7: Open UnitTest1.cs
Open:
CalculatorAPI.Tests
↓
UnitTest1.cs
Delete the existing sample test code.
Replace it with:
using CalculatorAPI;
namespace CalculatorAPI.Tests
{
public class CalculatorTests
{
[Fact]
public void Add_TwoNumbers_ReturnsCorrectResult()
{
// Arrange
CalculatorService calculator = new CalculatorService();

// Act
int result = calculator.Add(10, 20);
// Assert
Assert.Equal(30, result);
}
[Fact]
public void Subtract_TwoNumbers_ReturnsCorrectResult()
{
// Arrange
CalculatorService calculator = new CalculatorService();
// Act
int result = calculator.Subtract(20, 10);
// Assert
Assert.Equal(10, result);
}
[Fact]
public void Multiply_TwoNumbers_ReturnsCorrectResult()
{
// Arrange
CalculatorService calculator = new CalculatorService();
// Act
int result = calculator.Multiply(5, 4);
// Assert
Assert.Equal(20, result);
}
[Fact]
public void Divide_TwoNumbers_ReturnsCorrectResult()
{
// Arrange
CalculatorService calculator = new CalculatorService();
// Act
double result = calculator.Divide(20, 5);
// Assert
Assert.Equal(4, result);
}
[Fact]
public void Divide_ByZero_ThrowsException()
{
// Arrange
CalculatorService calculator = new CalculatorService();
// Act and Assert
Assert.Throws&lt;DivideByZeroException&gt;(
() =&gt; calculator.Divide(10, 0)
);
}
}
}
