6. Register the Service with Dependency Injection
ASP.NET Core Practical – URL Routing and Dependency Injection
Question 6: Register StudentService with the ASP.NET Core Dependency Injection container using the Scoped
lifetime.
File: Program.cs
using RoutingDIExample.Services;
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllers();
builder.Services.AddOpenApi();
// Register StudentService with Dependency Injection
builder.Services.AddScoped<IStudentService, StudentService>();
var app = builder.Build();
if (app.Environment.IsDevelopment())
{
 app.MapOpenApi();
}
app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();
app.Run();
