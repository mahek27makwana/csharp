# 5. Configure Identity in `Program.cs`

Use:

```csharp
using Microsoft.AspNetCore.Identity;
using Microsoft.EntityFrameworkCore;
using SecurityApp.Data;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddDbContext<ApplicationDbContext>(options =>
    options.UseSqlite(
        builder.Configuration.GetConnectionString("DefaultConnection")));

builder.Services.AddDefaultIdentity<IdentityUser>()
    .AddRoles<IdentityRole>()
    .AddEntityFrameworkStores<ApplicationDbContext>();

builder.Services.AddControllersWithViews();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseStaticFiles();

app.UseRouting();

app.UseAuthentication();
app.UseAuthorization();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");

app.MapRazorPages();

app.Run();
```

### Important

These two lines are required for security:

```csharp
app.UseAuthentication();
app.UseAuthorization();
```

# 8. Protect Dashboard

Add `[Authorize]` before the Dashboard action.

```csharp
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;

namespace SecurityApp.Controllers
{
    public class HomeController : Controller
    {
        public IActionResult Index()
        {
            return View();
        }

        [Authorize]
        public IActionResult Dashboard()
        {
            return View();
        }

        [Authorize(Roles = "Admin")]
        public IActionResult Admin()
        {
            return View();
        }
    }
}
```

### Meaning

```csharp
[Authorize]
```

Only logged-in users can access the page.

```csharp
[Authorize(Roles = "Admin")]
```

Only users having the **Admin** role can access the page.

# 12. Create Admin and User Roles

For a simple exam implementation, add role creation in `Program.cs` before `app.Run()`:

```csharp
using Microsoft.AspNetCore.Identity;
```

Then:

```csharp
using (var scope = app.Services.CreateScope())
{
    var roleManager = scope.ServiceProvider
        .GetRequiredService<RoleManager<IdentityRole>>();

    string[] roles = { "Admin", "User" };

    foreach (var role in roles)
    {
        if (!await roleManager.RoleExistsAsync(role))
            await roleManager.CreateAsync(new IdentityRole(role));
    }
}
```

So the ending of `Program.cs` becomes:

```csharp
app.MapRazorPages();

using (var scope = app.Services.CreateScope())
{
    var roleManager = scope.ServiceProvider
        .GetRequiredService<RoleManager<IdentityRole>>();

    string[] roles = { "Admin", "User" };

    foreach (var role in roles)
    {
        if (!await roleManager.RoleExistsAsync(role))
            await roleManager.CreateAsync(new IdentityRole(role));
    }
}

app.Run();
```

### Viva Questions

**1. What is ASP.NET Core Identity?**  
It is a framework for implementing user authentication and authorization.

**2. What is authentication?**  
Authentication verifies **who the user is**.

**3. What is authorization?**  
Authorization determines **what the user is allowed to access**.

**4. What does `[Authorize]` do?**  
It restricts access to authenticated users.

**5. What does `[Authorize(Roles = "Admin")]` do?**  
It allows only users having the **Admin** role.

**6. What are the two roles in this practical?**  
`Admin` and `User`.

**7. What is logout?**  
Logout ends the user's authenticated session.

**8. What is IdentityRole?**  
It represents a role such as **Admin** or **User**.

**9. What database is used?**  
SQLite.

**10. What is the difference between authentication and authorization?**

```text
Authentication → Who are you?
Authorization  → What can you access?
```
